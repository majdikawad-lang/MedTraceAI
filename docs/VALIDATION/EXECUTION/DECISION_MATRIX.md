# MedTrace AI — Strategic Decision Matrix (GO / ITERATE / PIVOT)

## Overview
This decision framework evaluates empirical validation findings across eight core strategic dimensions to arrive at an evidence-grounded **GO**, **ITERATE**, or **PIVOT** recommendation.

---

## 8-Dimension Strategic Evaluation Framework

```
┌────────────────────────────────────────────────────────────────────────┐
│                     8-DIMENSION EVALUATION MATRIX                      │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Problem Validation    │ Is record fragmentation a real, severe pain? │
│ 2. Target User Alignment │ Are chronic patients & PCPs the right focus? │
│ 3. Product Utility       │ Does longitudinal timeline solve the pain?   │
│ 4. System Trust          │ Do users & doctors trust citations & graphs? │
│ 5. Safety Comprehension  │ Do users understand non-diagnostic boundary? │
│ 6. Workflow Fit          │ Does Doctor Brief fit PCP 15-min visits?     │
│ 7. Privacy Confidence    │ Are users comfortable with data controls?    │
│ 8. Economic Value        │ Is there evidence of willingness to pay/pilot│
└────────────────────────────────────────────────────────────────────────┘
```

---

## Decision Threshold Criteria

### 🟢 `GO` (Proceed to Pilot Preparation & Commercial Scaling)
*Required Evidence Threshold:* **Level 4 Real User Evidence across all 8 dimensions.**
- **Problem Severity:** ≥ 80% of participants confirm fragmented medical records create major pain (Mean Score ≥ 4.0 / 5.0).
- **Product Comprehension:** 100% of participants understand MedTrace AI is an informational tool, not an AI doctor.
- **Physician Utility:** ≥ 75% of PCPs report Doctor Brief contains relevant pre-visit context that reduces chart review time.
- **Safety Boundary Integrity:** 0 Critical safety misinterpretations (no diagnostic or automated prescription assumptions).
- **Privacy & Business:** ≥ 80% confidence in sharing controls; clear willingness to pay or pilot.

---

### 🟡 `ITERATE` (Refine Product, Copy, or Doctor Brief Layout)
*Triggers:* **Problem is real, but specific UX, trust, or workflow friction points exist.**
- **UX / Copy Friction:** Users find terms like *"Information Gap"* or *"Medical Blind Spot"* ambiguous or alarming.
- **Doctor Brief Clutter:** Physicians request hiding stable lab values to keep brief strictly 1 page.
- **Citation Clarity:** Users request clearer DOI link previews on evidence cards.
- **Action:** Implement UX/copy refinements and re-test with 5–8 participants before proceeding.

---

### 🔴 `PIVOT` (Fundamental Re-Alignment of Product, User, or Business Model)
*Triggers:* **Core assumptions are empirically refuted by Level 4 evidence.**
- **No Real Pain:** Patients report portal PDF folders are fully sufficient and experience no fragmentation pain.
- **Physician Rejection:** Clinicians state reviewing AI brief takes more verification time than reading raw EHR records.
- **Unmanageable Safety Risk:** Users consistently interpret outputs as binding automated medical diagnoses despite safety gate barriers.
- **Zero Economic Value:** Neither patients, clinics, nor health systems show willingness to use, pay, or pilot.
- **Action:** Re-evaluate target user persona, core product offering, or clinical value proposition.
