# MedTrace AI — Session Likert Scorecard

## Overview
This scorecard provides a 1-to-5 Likert quantitative scoring system across 15 core product and clinical evaluation dimensions. Every numerical score must be accompanied by qualitative participant evidence notes and a confidence level rating.

> [!IMPORTANT]
> **Qualitative Evidence Rule**  
> Never interpret or report a numerical scorecard rating in isolation without citing empirical participant actions, task completion notes, or direct quotes.

## Metric Anchors

- **1 = Unusable / Severe Misunderstanding / High Risk / Zero Value**
- **2 = Poor / Confusing / Low Trust / Marginal Value**
- **3 = Acceptable / Moderate Utility / Requires Refinement**
- **4 = Strong / Clear / High Trust / Valuable**
- **5 = Exceptional / Immediately Understood / Essential Utility**
